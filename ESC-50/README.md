# Audio-Datasets
A collection of audio datasets used in my machine learning and deep learning projects.

## Datasets
### ESC-50
ESC-50 is a dataset for Environmental Sound Classification containing 2,000 labeled audio recordings across 50 environmental sound classes.
- 2,000 audio recordings
- 50 environmental sound classes
- 5-second audio clips
- WAV format
- 5 major categories
The original ESC-50 dataset is provided by Karol J. Piczak.
For detailed information about the dataset, its license, and citation requirements, see the `ESC-50` directory.

## Purpose
This repository is used to store and organize audio datasets for my current and future machine learning and deep learning projects.
